## 3. 확정된 진행 방향

### 검증

- 이번 프로젝트는 **Cross-Validation 없이 셀 단위 Hold-out**으로 진행한다.
- Batch 1의 셀을 학습·검증으로 분리하고, Batch 2에서 최종 평가한다.
- 동일 셀의 사이클을 학습·검증 양쪽에 넣지 않는다.
- 후보 모델은 동일한 분할로 비교한다. 셀 ID와 random seed를 기록한다.
- 전처리는 학습 데이터에서만 학습한다. Batch 2로 튜닝하지 않는다.
- 평균 지표뿐 아니라 셀별 실제값, 예측값, 오차, 충전 조건을 확인한다.
- 원문에는 CV 평균 보고 항목이 있으나 이번에는 미실시로 명시한다. 학습셋 예측 점수를 CV 평균으로 대체하지 않는다.
- 분할 비율, 구체적인 셀 목록, 프로토콜 기준 그룹 분리 여부는 아직 미정이다.
- 분할·모델의 공통 seed, Python·패키지·데이터 버전을 기록한다. 샘플링이 필요하면 학습 데이터 안에서만 적용하고 테스트 분포는 유지한다.
- 후보 모델 비교·튜닝은 Batch 1 Hold-out에서 수행하고, 피처·모델 확정 후 Batch 2 최종 테스트를 한 번 평가한다.
- 가이드 5·8장은 Train 내부 CV와 CV 평균을 명시한다. 현재의 CV 미실시 방침과 차이가 있으므로 CV 항목은 미실시로 표시하고, Train–Valid Gap을 포함한 제출 표 조정은 확인한다. 학습셋 점수를 CV 평균으로 대체하지 않는다.

### 분석·보고서

- README 구성은 루트의 `README_EXAMPLE.md`를 따른다. 샘플 파일 구조 대신 실제 분석·실행 관련 파일을 표시한다.
- 분석은 `.ipynb`로 작성하고 설명·코드·결과·해석을 함께 담는다. README에서 내부 인계·작업 기록 문서를 별도로 안내하지 않으며, README의 필수 요약 항목과 DAY 1 설계 PDF 제출은 유지한다.
- EDA는 그래프 나열이 아니라 **질문, 근거, 관측, 해석, 시사점**으로 작성한다.
- 발견한 특성이 전처리·피처·모델·검증에 어떻게 반영됐는지 설명한다.
- 오늘은 후보 피처를 계산·탐색하고 계산식·입력 구간·단위·EDA 근거·결측 처리안·보류 이유를 정의한다. 최종 피처 조합은 다음 날 Batch 1 학습·검증으로 확정한다.
- 실제 관측과 원인 가설을 구분한다. 상관관계를 인과관계로 단정하지 않는다.
- PdM을 배터리 선별·점검·교체 계획과 연결하되 완성된 예지보전 시스템으로 주장하지 않는다.
- 배터리 충전 방식, C-rate, 프로토콜별 수명 차이를 중점 확인한다.
- 공장 증가와 발전 부족은 사용자의 문제의식이다. 지역·기간·근거를 확인하기 전 사실로 확정하지 않는다. 발전 부족과 전력망 병목을 구분한다.
- ESS는 발전원이 아니다. 저장·시간대 이동·피크 완화의 역할을 설명한다.
- 데이터 분석 전에 예측 사용자·시점·지원할 의사결정과 분석 가설을 정의한다. 셀 단위 예측과 사이클 단위 측정, 변수 단위·척도·0의 의미를 구분한다.
- EDA의 관측 근거·해석·한계·처리 및 피처 선택·후보 모델 이유를 연결표로 작성한다.
- 운영 데이터의 분포 변화, 재학습, 추가 현장 검증은 향후 제언으로 다룬다. 비용 절감·안전성·충전 최적화 효과를 이번 프로젝트에서 실증했다고 주장하지 않는다.

## 5. 예제 노트북 사용 시 주의

- 현재 기본 EDA는 Batch 1 중심이며, 과제 전체 구현이 아니다.
- 데이터 경로는 작성자 로컬 경로이므로 실제 위치에 맞춰 변경해야 한다.
- `.mat` 파일의 구조, 셀 수, 사이클 번호, 결측 및 배열 정렬을 먼저 확인한다.
- 일부 그래프의 색은 수명순이 아닌 셀 순서에 기반한다. 색을 수명으로 해석하지 않는다.
- 일부 EOL 선의 0.88 계수는 잘못된 비율이다. 논문 EOL은 공칭 1.1 Ah의 80%인 **0.88 Ah**이며 셀별 초기 용량 기준과 구분한다.
- 용량이 낮다는 이유만으로 실제 열화 구간을 삭제하지 않는다.
- 원본 데이터는 보존하고 제거·수정 내역을 기록한다.
- Qdlin 전압 축은 가이드 2–3.6 V와 논문 3.5–2.0 V에 차이가 있어 실제 파일에서 확인한다.
- 회귀 ΔQ100−10의 로그 분산, 분류 ΔQ5−4의 분산을 문헌 기반 후보로 검토한다. 회귀 Elastic Net·분류 규제 Logistic Regression은 후보이며 최종 모델로 확정한 것이 아니다.
- 논문 분할·제외 조건과 우리 Batch 1 Hold-out·Batch 2 테스트는 다르다. 공식 코드의 인덱스는 현재 파일 매핑 전 적용하지 않는다.
