# 과제 가이드 대비 진행 상태 점검

기준 문서: [ESS Project_GUIDE.md](ESS%20Project_GUIDE.md). 점검일: 2026-10-02. 코드·저장 산출물·노트북 내용을 대조했으며 원본 가이드는 수정하지 않았다. 이번 점검은 현재 파일을 확인한 것으로 전체 노트북을 재실행하거나 외부 제출을 검증한 것은 아니다.

## 전체 판단

필수 모델링 흐름인 Regression 선택, 초기 100사이클 피처, Batch 1 셀 단위 Train/Hold-out과 Train CV, Batch 2 평가, MAPE와 Gap 해석은 구현했다. 목표 MAPE 9.1%는 달성하지 못했다. EDA의 모든 질문을 모든 배치에서 완결한 상태는 아니며, 성능 CSV의 필수 리포팅 형식과 제출 검증도 남아 있다. 따라서 프로젝트 방향은 가이드에 맞지만 제출 요구 전체를 완료했다고 표현하지 않는다.

## 가이드의 설명과 실제 관측이 다른 부분

1. 가이드3.3은 Batch1·2 수명 분포가 유사하다고 설명한다. 현재 파일의 중앙값은858.5/472사이클이고<500셀은0/28개로 달랐다. 가정에 맞춰 데이터를 제거하지 않고 관측을 보고했다.
2. 가이드는2018-02-20을 원논문1차 테스트셋으로 부른다. 과제 평가 역할은 그대로 따랐지만 공식 코드의2017-06-30과 같다고 해석하지 않는다. 출처 상세는 추가 참고사항에 둔다.
3. Qdlin 축은 가이드2.0~3.6V 대신 원본2.0~3.5V를 사용했다. 실제 배열에 맞춘 보정이다.
4. 가이드의 셀별 초기 용량80% 설명과 논문의 공칭1.1Ah의80%=0.88Ah는 다르다. 모델 타깃은 제공cycle_life를 유지하고 임의 재정의하지 않았다. 관측 이력은 참고사항에 기록한다.
5. 정책의 C2는0~80% 내 두 번째 구간이다.80%이후 공통1C CC-CV를 구분해 설명했다.
6. Gap 부호는 가이드 정리 메모에 따라 MAPE의 뒤 단계−앞 단계로 통일했다. 명칭이 달라도 Valid−Train,Test−Valid,Test−9.1의 계산과%p단위를 명시했다.
