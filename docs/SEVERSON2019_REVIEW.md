## 1. 핵심 요약

배터리의 초기 방전 용량이 거의 줄지 않았어도 **전압에 따른 방전 용량 곡선의 변화**에는 수명을 설명하는 신호가 있을 수 있다. 논문은 초기 사이클의 방전 곡선 차이 ΔQ(V)를 요약한 피처와 규제 선형 모델로 총수명 회귀와 장·단수명 분류를 수행했다.

우리 프로젝트에서 우선 참고할 내용은 다음과 같다.

1. 초기 용량의 증가를 곧바로 측정 오류로 제거하지 않는다.
2. 회귀 후보의 핵심으로 `Q100(V) - Q10(V)`의 분산과 로그 분산을 탐색한다.
3. 분류를 선택하면 초기 5사이클 안의 `Q5(V) - Q4(V)` 분산을 검토한다.
4. Elastic Net과 로그 수명 회귀를 후보 전략에 포함한다. 모델과 최종 피처는 실제 검증 후 선택한다.
5. 논문 요약 성능과 개별 테스트셋 성능, 논문 분할과 우리 분할을 구분한다.

근거: PDF pp. 1–7, Fig. 1–3, Table 1–2, Methods.

## 2. 연구 목적과 실험 데이터

수명이 긴 배터리를 끝까지 시험하면 피드백을 얻는 데 시간이 오래 걸린다. 초기 관측으로 수명을 예측할 수 있다면 제조 공정 검증, 셀 선별, 팩 구성과 충전 조건 탐색에 도움이 된다. 논문은 특정 열화 기전을 사전에 모델에 넣기보다, 실험 데이터를 통해 예측 피처를 찾는 접근을 취했다.

| 항목 | 논문에서 확인한 내용 |
| --- | --- |
| 셀 | 상용 A123 APR18650M1A, LFP/흑연 |
| 공칭용량·전압 | 1.1 Ah, 3.3 V |
| 분석 데이터 | 124개 셀, 약 96,700사이클 |
| 수명 범위 | 약 150–2,300사이클; 평균 806, 표준편차 377 |
| 실험 환경 | 30°C 챔버; 셀 온도는 충·방전 중 변할 수 있음 |
| 충전 조건 | 72개 정책; 0–80% SOC 구간의 1단계·2단계 고속 충전 조건을 변경 |
| 공통 충전 구간 | 80–100% SOC는 1C CC-CV |
| 방전 조건 | 공통 4C CC-CV, 2.0 V까지 방전 |
| 수명 종료 | 공칭용량의 80%, 즉 0.88 Ah 도달을 기준으로 총사이클 수 정의 |

근거: PDF p. 2, Data generation; p. 7, Methods.

**프로토콜 해석 보정:** 두 고속 C-rate는 0–80% SOC 구간 안에서 적용된다. 예를 들어 논문의 6C/4C 예시는 0–50%를 6C, 50–80%를 4C로 충전하고, 이후 80–100%는 공통 1C다. 정책 표기의 마지막 C-rate가 완충까지 적용된다고 가정하지 않는다. 우리 파일의 정책 문자열과 실제 I·V·t를 확인하여 구간을 해석한다.

**EOL 해석 보정:** 논문의 80%는 셀별 첫 측정 용량이 아닌 공칭용량 기준이다. 셀별 초기 용량으로 정규화한 그래프를 그릴 수는 있지만, 그 기준으로 기존 `cycle_life`를 임의로 다시 정의하지 않는다.

## 3. EDA에서 얻을 지식

### 3.1 초기 용량 자체는 약한 신호일 수 있다

Fig. 1은 초기 100사이클에서 셀의 용량 곡선이 겹치거나 교차하여 수명 순위를 명확히 구분하기 어렵다는 점을 보인다. 논문 데이터에서는 81%의 셀이 100사이클에 초기보다 용량이 증가했고, 초기 대비 증가율 중앙값은 약 0.2%였다.

Fig. 1의 로그 수명과의 상관계수는 2사이클 용량 약 −0.06, 100사이클 용량 0.27, 95–100사이클 용량 기울기 0.47이다. 가장 짧은 수명의 셀을 제외하면 뒤의 두 값이 각각 0.08, 0.36으로 바뀐다. 개별 극단값이 상관 해석에 미치는 영향도 확인해야 한다.

**우리 적용:** 초기 용량·용량 변화량은 후보로 관측하되, 음의 변화만 정상으로 가정하지 않는다. 전체 셀과 특이 셀을 포함·제외한 설명용 비교는 구분해서 제시하고, 수명이 짧다는 이유만으로 학습·평가에서 제외하지 않는다. 논문 수치를 우리 Batch 1 통계로 옮기지 않는다.

근거: PDF pp. 2–4, Fig. 1 및 본문.

### 3.2 ΔQ(V)가 총용량에 드러나지 않는 변화를 포착한다

동일한 전압 축에서 사이클별 방전 용량 Q(V)를 비교한다.

```text
ΔQ100−10(V) = Q100(V) − Q10(V)
variance_feature = Var(ΔQ100−10(V))
log_variance_feature = log(Var(ΔQ100−10(V)))
```

논문은 분산·최솟값·평균 등의 통계량을 검토했고, 로그 분산 하나만 사용하는 회귀 모델도 의미 있는 예측력을 보였다. Fig. 2c의 로그–로그 관계는 강한 음의 상관을 보인다. 그림 표기 −0.92와 캡션 −0.93이 조금 달라, 약 −0.92∼−0.93으로 기록한다. 이는 논문 데이터의 관계이며 우리 데이터에서 재확인해야 한다.

Methods는 방전 곡선을 spline으로 맞춘 뒤 **3.5 V에서 2.0 V까지 1,000개 균등 전압점**에서 평가했다고 설명한다. 가이드의 2.0–3.6 V 표기와 차이가 있다. 파일의 실제 전압 벡터·배열 길이·정렬 방향·사이클 매핑을 먼저 확인한다. 1,000개라는 길이만으로 서로 같은 축이라고 판단하지 않는다.

**우리 적용:** 회귀 후보의 우선 탐색 항목으로 분산·로그 분산·최솟값·평균을 기록한다. 로그의 밑과 분산 계산 규칙을 정의표에 명시한다. 분산이 0이거나 값이 비유한 경우 임의의 작은 상수를 넣기 전에 계산 가능 여부와 처리 근거를 기록한다. 이 후보 목록은 본문에서 확인한 범위이며 논문의 전체 피처 목록을 재현한 것은 아니다.

근거: PDF pp. 3–4, Fig. 2; p. 7, Methods.

### 3.3 물리 해석은 예측 근거와 구분한다

논문은 초기 용량에는 드러나지 않지만 전압 곡선을 바꾸는 열화 기전을 논의한다. 탈리튬 상태 음극의 활성물질 손실(LAMdeNE)과 리튬 재고 손실이 곡선을 변화시키고, 이후 급격한 용량 저하와 연결될 수 있다는 설명이다. 별도 저율 진단 실험을 통해 이 해석과 일관되는 현상을 확인했다.

고속 충·방전에서는 미분 곡선의 특징이 흐려질 수 있고, 수치 미분은 노이즈에 민감하다. ΔQ(V)의 요약 통계는 저율 진단 사이클이나 수치 미분에 의존하지 않고도 신호를 얻는 방법이다.

**우리 적용:** “총용량 변화가 작아도 곡선 변화에는 예측 신호가 있을 수 있다”를 ΔQ 피처의 도메인 근거로 쓴다. 우리 셀의 ΔQ만으로 특정 열화 기전이 발생했다고 확정하지 않는다. dQ/dV를 처음부터 필수 구현으로 늘리지 않고 ΔQ 요약 통계를 먼저 검토한다.

근거: PDF pp. 5–6, Fig. 4–5.

## 4. 모델과 후보 피처 설계

회귀는 **피처의 선형 결합으로 로그 수명**을 예측하고 Elastic Net 규제를 적용한다. 선택 이유는 해석 가능성, 작은 계산 비용, 상관된 피처에 대한 대응이다. 선형 모델을 사용하더라도 입력 피처 자체는 원자료의 비선형 변환일 수 있다.

| 설정 | 논문 내용 | 우리 프로젝트에 제안하는 검토 |
| --- | --- | --- |
| Variance 회귀 | ΔQ100−10의 로그 분산 1개 | 가장 단순한 문헌 기반 기준 모델 후보 |
| Discharge 회귀 | 방전 정보의 13개 후보 중 6개 선택 | ΔQ와 초기 용량 관련 신호를 단계적으로 추가 |
| Full 회귀 | 온도·저항 등 포함, 20개 후보 중 9개 선택 | 추가 센서의 결측·신뢰도와 실제 검증 이득 확인 |
| Variance 분류 | ΔQ5−4의 분산 | 초기 5사이클 분류 후보 피처 |
| Full 분류 | 규제 Logistic Regression, 후보 18개 | 작은 표본의 분류 후보 모델 |

근거: PDF pp. 3–5; 회귀의 전체 후보 정의는 Supplementary Table 1, 분류는 Supplementary Note 4 등을 참조하므로 이 PDF만으로 정확한 전체 목록·선택 계수·설정을 확정하지 않는다.

로그 타깃 회귀를 구현하면 예측을 원래 사이클 단위로 되돌린 후 MAPE·RMSE를 계산해야 한다. 회귀 목표는 총 `cycle_life`이며, 현재 시점 이후 RUL과 구분한다. 분류의 기본 라벨은 과제 가이드에 따라 `cycle_life >= 550`이다.

오늘은 후보 피처를 계산·탐색하고 정의표를 만든다. 단변량 모델·Elastic Net·규제 Logistic Regression은 후보 전략으로 기록하며, 최종 채택·피처 조합은 다음 날 Batch 1 학습·검증으로 결정한다.

## 5. 평가 결과를 읽는 방법

### 5.1 회귀의 세부 성능은 요약 9.1%와 구분한다

본문의 평균 백분율 오차는 다음 식으로, 우리 과제의 MAPE와 같은 형태다.

```text
MAPE (%) = mean(abs(y − prediction) / y) × 100
RMSE (cycles) = sqrt(mean((y − prediction)^2))
```

논문 Table 1(PDF p. 4)의 값은 다음과 같다. 괄호는 primary test의 급격한 용량 저하를 보인 셀 1개를 제외한 값이다.

| 회귀 모델 | Train MAPE (%) | Primary MAPE (%) | Secondary MAPE (%) | Train RMSE | Primary RMSE | Secondary RMSE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Variance | 14.1 | 14.7 (13.2) | 11.4 | 103 | 138 (138) | 196 |
| Discharge | 9.8 | 13.0 (10.1) | 8.6 | 76 | 91 (86) | 173 |
| Full | 5.6 | 14.1 (7.5) | 10.7 | 51 | 118 (100) | 214 |

RMSE 단위는 사이클이다. Full 모델은 온도 센서 접촉 문제가 있었던 셀 4개를 추가 제외한다(Fig. 3 캡션). 따라서 모델끼리 동일 셀을 평가했다고 가정하지 않는다.

초록·결론의 9.1%를 Table 1의 primary test 성능으로 쓰면 안 된다. 제공 PDF는 개별 테스트셋의 위 값도 함께 보고하므로, 요약 9.1%의 정확한 집계·제외 조건은 보충자료 확인 전 확정하지 않는다. 우리 제출에서는 **과제 비교 목표 9.1%**와 **우리 Batch 2 MAPE**를 구분하고 조건 차이를 설명한다.

### 5.2 분류의 95.1%도 primary test 단독 점수가 아니다

Table 2(PDF p. 4)는 수명 임계값 550에서 다음 Accuracy를 보고한다.

| 분류 모델 | Train (%) | Primary test (%) | Secondary test (%) |
| --- | ---: | ---: | ---: |
| Variance | 82.1 | 78.6 | 97.5 |
| Full | 97.4 | 92.7 | 97.5 |

본문(PDF p. 5)의 대표 test Accuracy는 Variance 88.8%, Full 95.1%다. 이 수치와 위 테스트셋별 값의 집계 조건을 구분한다. F1 값은 본문 Table 2에 없으므로 추정해 채우지 않는다.

### 5.3 분할은 우리 과제와 다르다

논문 본문은 train 41개, primary test 43개, 모델 개발 후 생성한 secondary test 40개를 설명한다. Methods는 모델 개발 데이터에서 train·primary test를 나누고, 학습 내부 **4-fold CV와 Monte Carlo sampling**으로 규제 파라미터를 정했다고 명시한다(PDF pp. 4, 7). 논문의 Train 열은 모델 학습에 사용한 데이터의 성능이며, 과제의 “Train CV 평균” 열과 동일하다고 단정하지 않는다.

우리 현재 방침은 Batch 1 셀 단위 Hold-out, Batch 2 최종 테스트, CV 미실시다. 논문 재현이라고 표현하기보다 **논문 기반 피처·모델을 다른 분할에서 평가**한다고 설명한다. 과제의 CV 보고 요구와 차이는 기존 확인 사항으로 유지한다.

MAPE만으로 셀당 절대 사이클 오차를 알 수 없으므로, 우리 결과에는 보조 RMSE와 셀별 실제값·예측값·오차를 함께 남기는 것을 제안한다. 오류가 큰 셀을 목표 성능 달성을 위해 사후 제거하지 않는다.

PDF Methods와 MATLAB 코드는 두 번째 실험을 `2017-06-30`으로 표기하지만 우리 파일은 `2018-02-20`이다. 날짜·파일 버전·셀 목록의 대응은 현재 파일 확인이 필요하다. 공식 코드의 제거 인덱스를 우리 파일에 그대로 적용하거나 셀 수를 124개로 맞추기 위해 삭제하지 않는다. 공통 물리 셀이 학습·테스트에 중복되는지 확인하는 점검 항목으로 사용한다.

이 공식 코드 확인은 식별·전처리 점검을 위한 것이다. 최신 작업 기록의 Batch 2 역할 격리 방침에 따라 Batch 2 라벨을 보고 피처·모델을 선택하지 않는다. 필요한 최소 무결성·중복 점검과 과제의 Batch 2·3 EDA 요구 간 범위 차이는 별도로 기록한다.

## 7. 기존 설명 중 보정하거나 근거를 더 확인할 내용

| 항목 | 논문 근거에 따른 정리 |
| --- | --- |
| EOL: 초기 용량의 80% | 논문은 **공칭 1.1 Ah의 80% = 0.88 Ah**. 과제 설명과 구분하고 파일 타깃 확인 |
| `0.88 × nominal` 기준선 | 0.88은 Ah 값, 0.80은 비율. 논문 기준은 0.88 Ah |
| Qdlin의 2.0–3.6 V 축 | Methods는 **3.5–2.0 V**. 현재 파일 실제 축 확인 필요 |
| 정책의 두 번째 고속 C-rate가 완충까지 적용 | 정책 변화는 0–80% SOC; 80–100%는 공통 1C |
| 초기 용량이 증가하면 오류 | 논문에서도 초기 용량 증가가 관측됨. 값의 크기·패턴·실험 조건을 함께 판단 |
| 분류 ΔQ 정의 미확정 | 본문은 **Q5−Q4 분산**을 명시 |
| 논문의 Train/Primary가 Batch 1/2와 동일 | 공식 분할은 초기 배치 결합 후 선택. 우리 분할과 다름 |
| 대표 9.1%·95.1%가 Batch 2 단독 성능 | Table 1·2의 primary 값과 다름. 비교 조건을 명시 |
| Tmin=0의 원인이 장비 초기화라고 확정 | 이 PDF는 우리 Tmin=0의 원인을 입증하지 않음. 원자료·장비 정의 확인 전 원인 가설로 기록 |
| 우리 CE>100%가 특정 원인·정확도로 정상이라고 확정 | 논문의 초기 용량 증가 설명만으로 쿨롱효율의 원인이나 ±0.05% 정확도를 입증할 수 없음. 충·방전 구간·적분·측정 조건 확인 필요 |

본문의 센서 접촉 문제는 온도 데이터의 신뢰도 점검 근거다. 그러나 이를 우리 특정 0 값이나 400°C 값의 원인 규명으로 대체하지 않는다. 관측된 값, 판단 기준, 가능한 원인과 확정된 원인을 구분한다.
