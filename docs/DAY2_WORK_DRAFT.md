## 3. 비교와 평가 규칙

기존 단일 Hold-out 설계를 유지하면서 가이드의 Train CV 요구를 충족하도록 **Train 내부 3-fold CV 추가를 이번 초안에서 제안**한다. 아직 학습·CV를 실행하지 않았으며 확정된 성능은 없다.

- 성능 지표는 MAPE(%), Gap은 %p다. Train 재예측 점수와 Train CV 평균을 혼동하지 않는다.
- Ridge의 alpha는 0.1·1·10, RandomForest는 깊이 2·3과 최소 leaf 3·5 정도의 작은 후보 집합부터 검토한다. 후보 확장은 결과와 시간을 보고 결정한다.
- 기존 분할을 유지한다. 이번 제출의 Batch 2에는 Train 36셀로 적합하고 고정한 모델을 사용해 Valid/Test의 모델 조건을 일치시킨다. 46셀 재학습은 별도 후속 작업으로 구분한다.
- 기존 EDA에 Batch 1 전체 라벨이 사용됐다. Hold-out 결과를 탐색에서 완전히 독립된 성능으로 주장하지 않는다. Batch 2 라벨 분포도 이미 Q1에서 관측했으므로 완전 블라인드라고 표현하지 않는다.
- Batch 2·3 EDA 상관은 모델·피처 선택 기준으로 사용하지 않는다.
- 정책당 작은 표본과 Train/Val 정책 중복 때문에 정책 일반화 한계를 보고한다. 9.1%는 논문의 다른 실험 조건에서 얻은 비교 기준이며 반드시 달성해야 하는 완료 조건은 아니다.
