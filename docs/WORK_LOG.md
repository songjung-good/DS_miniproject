# 프로젝트 작업 기록

## 기록 원칙

이 프로젝트에서 작업할 때 완료한 작업, 확인한 결과, 판단 근거, 다음 작업을 이 문서에 업데이트한다. 실행하지 않은 분석이나 검증하지 않은 가설은 완료 결과로 기록하지 않는다.

## 협업 방식

사용자는 데이터 전문 지식 없이도 결과를 판단할 수 있도록 분석의 목적과 해석을 함께 확인한다. 분석 작업은 다음 단위로 설명하고 진행한다.

1. **질문**: 무엇을 확인하려는가?
2. **산출물**: 어떤 그래프나 표가 필요한가?
3. **관측**: 데이터에서 실제로 무엇이 나타났는가?
4. **해석·한계**: 어떤 의미가 있으며, 아직 단정할 수 없는 것은 무엇인가?
5. **결정**: 전처리·피처·모델·검증에 무엇을 반영할 것인가?
6. **보고 내용**: 제출물에 어떤 그림과 설명을 넣을 것인가?

분석마다 핵심 산출물을 먼저 검토한다. 관측 결과와 원인 가설을 구분하고, 변경 전후 결과를 비교한다. 결측치나 이상치를 이유 없이 삭제하지 않는다.
